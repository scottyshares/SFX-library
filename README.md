# SFX Library

Scotty's personal sound-effects library for video editing (297 sounds, from the Muaaz SFX Pack).
Private: some clips are recognizable brand/app sounds, so this repo should not be made public.

- `CATALOG.md`: every sound by category, with length in seconds
- `catalog.csv`: the same list in machine-readable form
- `CLAUDE.md`: how Claude Code should use this library in an editing session
